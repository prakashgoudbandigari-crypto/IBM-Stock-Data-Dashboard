# IBM Stock Data Dashboard

## Project Overview
This project focuses on extracting, analyzing, and visualizing stock market data using Python. Historical stock prices were collected using yFinance, while company revenue data was extracted using web scraping techniques.

## Stocks Analyzed
- Tesla (TSLA)
- GameStop (GME)

## Technologies Used
- Python
- Pandas
- yFinance
- BeautifulSoup
- Requests
- Plotly

## Features
- Historical stock price extraction
- Revenue data extraction using web scraping
- Data cleaning and preprocessing
- Interactive Plotly dashboards
- Financial trend analysis

## Dashboard Visualizations
The project includes interactive dashboards that compare:
- Historical Share Price
- Historical Revenue

## Learning Outcomes
- Web Scraping with BeautifulSoup
- Financial Data Analysis
- Data Visualization using Plotly
- Dashboard Development
- Python Data Science Workflow
